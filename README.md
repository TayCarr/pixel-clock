# pixel-clock
Taylor Carreiro 2026

Web app that displays the time (and weather) for other locations. Typescript Vite, after that npm run dev to run it locally, not sure if I will ever host it. Oh you will need to get an API key from https://openweathermap.org and chuck it in .env as: VITE_WEATHER_API_KEY={keyhere}

I have a lot of friends that live not near me and I find I am always asking them "What time is it for you?" and so with this I don't need to ask them ! Hopefully I can come up with some fun ideas and make this cute! I am using Typescript for the very first time so I am getting lots of google help on the skeleton and hopefully can figure things out as I go otherwise I will be sad and wish I went with React since I am more familiar with that route... I also have never done any pixel art so ummm that might be a bit of a learning curve. 

Currently it has two static cities, shows the time in 12hr and has a pixel showing current weather followed by string description.
